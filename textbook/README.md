# Kursboken

1. Lägg bok-PDF:en här och döp om den till **`book.pdf`**.
2. Gör det på **varje dator** (både stationära och laptop). Boken pushas aldrig till GitHub, eftersom den är upphovsrättsskyddad.
3. `INDEX.md` innehåller innehållsförteckningen med PDF-sidnummer. Den finns på GitHub, så Claude vet var allt står i boken.
