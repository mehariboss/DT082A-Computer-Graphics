# Project – DT082A Computer Graphics

The project constitutes a central part of DT082A and is performed in small groups of 2 students. The work spans multiple course weeks and integrates concepts, tools, and methods introduced in the early lectures.

## Group formation

You are encouraged to create your own groups:

- Form groups under **People** in the Canvas left menu.
- Each group should ideally consist of 2 students.

If you have not joined a group by the project start (end of week 48), you will be assigned to a group by the lecturers.

## Project selection

1. First, please make yourselves acquainted with the project ideas provided below.
2. Second, create and submit a project topic proposal as part of the assignment with the same name. The proposal should contain:
   - Project title
   - Short project objective with motivation
   - Methodology and expected learning value
   - Relevant references and links
3. Third, wait for a response on the submitted proposal with either a go to start the project, or a request to supplement with information to make the proposal suitable for the project.
4. Finally, start the project design and implementation phase.

## Project design and implementation

- The project implementation period "officially" starts in week 49. Then, you will implement the task (which will take 2–3 weeks) in groups of 2 students, applying the concepts learned in the initial lectures, using the tools taught and given.
- You will be given the opportunity for mentoring sessions in week 51.

Mentoring sessions will be held in **L401** (schedule table on Canvas: date, time, group ID, project topic, team members – not yet filled in).

## Peer review & discussions

- The students will then report their work through the "must-have" slides (these slides should be treated as the minimum, but can be supplemented with more slides in the final presentation) and submit it in week 02.
- The project part of the course will culminate in a presentation session in week 02, where groups share their projects and learnings.
- During the final presentation, the students shall pose each other questions and discuss their findings and projects. Each group will be an "opponent" to another group. That is, the assigned group shall ask more questions to the relevant group.

## Project evaluation & final project presentations

The projects need to be presented by the team members in week 02 (written as "2026-01-08" on Canvas; the session is in January 2027). The final project presentation session is not only an assessment activity but also a peer-learning opportunity. Therefore, all groups must attend the entire presentation session.

The projects will be evaluated based on:

- technical depth (i.e., understanding and application of algorithms and techniques),
- implementation quality and complexity,
- projects' relevance to learning outcomes,
- creativity and innovation,
- and reflections.

## Project topics

Three project ideas are provided on Canvas (downloadable file) as inspiration, but feel free to propose a topic within computer graphics that you find interesting and suitable for a short project work.
