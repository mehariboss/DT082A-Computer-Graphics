# DT082A Computer Graphics – HT2026

Kursrepo för DT082A (WebGL) på Mittuniversitetet: föreläsningar, labbar och projekt.

| Mapp | Innehåll |
|---|---|
| `lectures/` | Föreläsningsbilder (PDF + text) |
| `labs/` | Lab 1 och Lab 2 |
| `project/` | Ämnesförslag, kod och presentation för projektet |
| `notes/` | Egna anteckningar |

## Köra WebGL-koden
1. Installera VS Code-tillägget **Live Server**.
2. Högerklicka på `index.html` → *Open with Live Server*.
